BRIEFforbind API browser — assumptions before you read the options

What I assumed

  • Schema is uploaded per session, 30–150 endpoints, so search + tag grouping beats deep tree nav.
  • Accessibility is invisible-but-correct: no badges, no a11y panel. It shows up as focus visibility, real semantics, and never colour-only meaning.
  • curl is the only snippet language for now; the code block is built to take more later.
  • Four audiences, one UI — density is the lever, not separate modes.

The system

  • Near-black #0F0F0E on near-white #FBFBF9. Hairlines are structure; no shadows anywhere.
  • IBM Plex Sans for prose, IBM Plex Mono for anything the API literally says.
  • One accent, #1A3FB8, reserved for focus and selection. Never decoration.
  • HTTP verbs always carry their word. Tint is redundant reinforcement only.

Open with you

  • I couldn't read the forbind folder from here — this sets a direction rather than matching your existing shell.
  • Try-it-out and live responses aren't drawn yet; the detail pane leaves room for them.
